## Chapter 2: LLM-based Task Planning

### Learning Objectives:
*   Design a prompt for an LLM to convert a natural language command into a sequence of robot actions.
*   Create a ROS 2 node that queries an LLM and publishes the action plan.

### Overview

Large Language Models (LLMs) are revolutionizing how robots can interpret and plan for complex tasks from high-level natural language instructions. This chapter explores how to leverage LLMs for task planning, moving from a transcribed voice command to a structured sequence of robot actions. You will learn to design effective prompts and integrate an LLM into your ROS 2 robot control system.
