## Chapter 2: Simulating Sensors

### Learning Objectives:
*   Add a simulated LiDAR to a robot model.
*   Add a simulated depth camera and visualize its point cloud.
*   Read data from a simulated IMU.

### Overview

Accurate sensor data is paramount for any robot's perception and decision-making. This chapter focuses on how to integrate and configure various simulated sensors into your robot model within the chosen physics simulation environment. You will learn to add a LiDAR, a depth camera, and an Inertial Measurement Unit (IMU), and how to access their data streams.
