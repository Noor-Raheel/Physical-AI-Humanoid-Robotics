## Chapter 3: Defining Your Robot with URDF

### Learning Objectives:
*   Describe the purpose of the Unified Robot Description Format (URDF).
*   Create a simple URDF file for a multi-link robot.
*   Visualize the robot model in RViz.

### Overview

This chapter introduces the Unified Robot Description Format (URDF), an XML format for describing all aspects of a robot model. You will learn how to create a basic URDF file and visualize your robot in RViz, a 3D visualization tool for ROS 2.
