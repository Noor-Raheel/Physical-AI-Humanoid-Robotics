# Physical AI & Humanoid Robotics Course

This repository contains the content and associated code examples for a 4-module course on "Physical AI & Humanoid Robotics". The course bridges digital AI models with physical humanoid robots through technologies like ROS 2, Gazebo, Unity, and NVIDIA Isaac. The course content is delivered via a Docusaurus website.

## Project Structure

- `docusaurus-site/`: The Docusaurus project containing all course content (Markdown/MDX files), static assets, and website configuration.
- `specs/`: Specification and design documents for this course feature, including:
  - `001-humanoid-robotics-course/`: Feature-specific documents.
    - `spec.md`: The detailed feature specification.
    - `plan.md`: The implementation plan.
    - `tasks.md`: The actionable task list for development.
    - `research.md`: Outlines research questions and decisions.
    - `data-model.md`: Defines the course content structure.
    - `contracts/syllabus.yml`: The course syllabus with learning objectives.
    - `quickstart.md`: Guide for contributors.
- `.github/workflows/`: GitHub Actions workflows for CI/CD, including deployment to GitHub Pages.
- `.specify/`: Internal tools and templates for the Gemini CLI agent.
- `history/`: Prompt history records generated by the Gemini CLI agent.

## Course Overview

The course is structured into four main modules:

1.  **The Robotic Nervous System (ROS 2)**: Core middleware concepts and Python control.
2.  **The Digital Twin (Gazebo & Unity)**: Physics simulation, environment building, and sensor simulation.
3.  **The AI-Robot Brain (NVIDIA Isaac)**: Photorealistic simulation, synthetic data, and navigation.
4.  **Vision-Language-Action (VLA)**: Voice-to-action, LLM-based planning, and capstone project.

## Deployment

The Docusaurus website is deployed to GitHub Pages via a GitHub Actions workflow. Changes pushed to the `main` branch will automatically trigger a build and deployment.
